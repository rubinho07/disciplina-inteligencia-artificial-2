# Disciplina de Inteligência Artificial

Repositório destinado ao armazenamento das atividades e notebooks desenvolvidos durante a disciplina de Inteligência Artificial, utilizando Python e algumas das principais bibliotecas voltadas para análise e manipulação de dados.

## Conteúdo

### Exercícios de Python DataScience

Notebook contendo a resolução dos exercícios propostos na disciplina, utilizando as bibliotecas:

NumPy
SciPy
Pandas
Matplotlib

## SciPy

Exercícios envolvendo:

Cálculo de integrais
Equações diferenciais
Otimização de funções
Transformada de Fourier
Interpolação
Sistemas de equações lineares
Matrizes e determinantes
## Pandas

Exercícios envolvendo:

Criação de DataFrames
Leitura de arquivos Excel e CSV
Filtragem de dados
Manipulação de colunas
Tratamento de valores nulos
Agrupamento de dados
Cálculo de média e mediana
Exportação de arquivos

Para alguns dos exercícios foi utilizada uma planilha de vendas contendo informações de produtos, preços e quantidades.

## Matplotlib

Exercícios envolvendo:

Gráficos de linha
Gráficos de barras
Histogramas
Gráficos de dispersão
Gráficos de pizza
Subplots
Gráficos 3D
Personalização de gráficos
Arquivos
